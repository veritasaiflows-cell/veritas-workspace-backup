- Self-improvement / operator correction on 2026-04-30: OpenClaw config changes must not guess config paths or conflate similarly named settings. Real lesson from the heartbeat issue: `web.heartbeatSeconds` and `agents.defaults.heartbeat.every` are different settings. Correct config workflow standard is: inspect active config file + schema + current value first, prefer `openclaw config set` over manual JSON editing when possible, validate with `openclaw config validate`, restart gateway after runtime-sensitive changes, verify with `openclaw config get` plus `openclaw status`, inspect `agents.list` for overrides when live behavior disagrees, and never expose tokens/OAuth/API keys/gateway secrets in logs or chat.
