## External Patterns Adopted (evidence, not authority)
- Routing vs orchestration vs handoff vs parallelization are distinct decisions; route first (one destination), then orchestrate. Six router patterns: rule-based, semantic, intent-based, LLM-based, hierarchical, auction-based; cheapest reliable shape is a layered cascade (rule check -> embedding match -> LLM classifier) keeping routing tax in single-digit percent. Ambiguous requests get one clarifying signal, never a silent guess. Source: Taskade 2026 routing guide (web fetch 2026-09-09). <!-- project: github.com/veritasaiflows-cell/veritas-workspace-backup -->
