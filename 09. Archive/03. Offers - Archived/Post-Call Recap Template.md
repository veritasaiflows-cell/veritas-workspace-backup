## Template

Hey [Name],

Good talking with you.

Here is my understanding of the situation:
- [main goals or competing priorities]
- [main bottleneck or execution breakdown]
- [what is currently not working]

The core problem does not look like a lack of ideas.
It looks more like a prioritization and execution system problem.

My recommendation would be a focused setup process that helps you:
- organize the active opportunities or priorities
- create a clearer way to rank what matters
- build a dashboard or workflow that improves visibility
- create a repeatable review rhythm and next-action path

If we move forward, the next step I would suggest is:
- [follow-up session / pilot / 1-week sprint]

That would likely include:
- diagnosis and inventory
- prioritization framework
- dashboard/workflow setup
- weekly review structure
- first action plan

If you want, I can send a short outline of what that would look like in practice.

## Purpose of this template

Use this after the call to:
- show that you understood the problem
- restate the bottleneck clearly
- position the next step as structured and useful
- move the conversation toward a real engagement
