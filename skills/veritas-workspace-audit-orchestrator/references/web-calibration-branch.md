# Web Calibration Branch

Read this only when the audit explicitly asks for external/web calibration.

## Handling

Use current primary or high-quality sources for patterns, then translate them into local, validator-backed OpenClaw controls. External patterns never override local finance authority, owner approval, or release-contract gates. An external pattern is a candidate, not a control, until a local validator backs it.

## Recommended Calibration Themes

- evals and regression suites for agents
- tracing and guardrails
- durable execution/stateful workflows
- human-in-the-loop approval boundaries
- routing/classification dockets
- control-plane observability

## Completion

State which themes were consulted, what local control each maps to, and which remain external-only. An uncalibrated audit is not evidence of a gap.
