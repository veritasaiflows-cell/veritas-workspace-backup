# Local Screen Recordings ($0)

Local clips for the interactive training modules live in this folder.
No LMS, no YouTube, no upload: everything stays on this machine.

## Capture (Windows, $0)

1. Press Win+Shift+R or open Snipping Tool and switch to video capture.
2. Record the walkthrough (keep it short and free of customer data or credentials).
3. Save the file under training/interactive-training-builder/recordings/ as .webm or .mp4.
4. Rerun python scripts\interactive_training_screen_capture.py --write --validate, then rebuild the training modules.
