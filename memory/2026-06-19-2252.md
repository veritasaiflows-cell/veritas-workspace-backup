MiniCPM-o is the more ambitious experiment. It tries to handle speech conversation directly. That is powerful but riskier for us because it could blur “audio model heard something” with “Veritas decided something.”

Orpheus is cleaner. It only speaks text. That makes it easier to keep GPT-5.5 in charge:

```text
GPT-5.5 writes final summary -> Orpheus speaks it
```
