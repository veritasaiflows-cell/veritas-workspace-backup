# Heartbeat Tasks

## Light continuity maintenance

Run this only on heartbeat polls.

1. Check whether today already has a daily note in `memory/YYYY-MM-DD.md`.
2. If meaningful work happened since the last write, append short factual bullets to today's daily note.
3. If recent daily notes contain durable truths, preferences, decisions, lessons, finance rules, or market posture changes, promote only the important ones into `MEMORY.md` or the correct operating file.
4. Do not spam. If there is nothing meaningful to record or promote, reply `HEARTBEAT_OK`.
5. Prefer silence at night unless something is genuinely important.
6. Keep `MEMORY.md` curated. Do not bloat it with raw logs.
7. If a lesson changes future behavior, update `AGENTS.md`, `TOOLS.md`, or another core file instead of only logging it in a daily note.
8. Do not nag about commits during heartbeats. Only mention commit batching when roughly 72 hours have passed or a checkpoint is genuinely important.

## Scheduler note

- Current default heartbeat cadence is every 4 hours.
- Keep heartbeat work lightweight unless something genuinely important needs attention.

## Finance staleness check

Run this lightly on heartbeat polls when useful, not every time.

1. Check whether any live finance file is stale relative to its own refresh policy:
   - `02. Markets/Macro Regime Dashboard.md`
   - `02. Markets/Watchlist.md`
   - `03. Portfolio/Portfolio Snapshot.md`
   - `03. Portfolio/Technical Entry and Invalidation Sheet.md`
   - `05. Intelligence/Weekly Intelligence Brief.md`
   - `05. Intelligence/Event Calendar.md`
2. Prefer checking freshness metadata and near-term catalysts, not redoing the full work.
3. If the technical sheet is older than 5 trading days, or a major earnings date / macro event is near, note that a refresh is due.
4. If the event calendar still contains elapsed critical one-time events, clean or flag it.
5. If the weekly intelligence brief is older than 7 days or overtaken by major events, flag it for refresh.
6. Stay quiet if everything important is still current.

## Constraints

- No mental notes. If it matters, write it.
- Prefer short accurate updates over long summaries.
- Do not repeat old tasks just because they existed in prior chats.
- Use heartbeat for light maintenance, not major new projects.
- In the current finance-first direction, prefer promoting durable risk rules, market views, and portfolio preferences over noisy market chatter.
