# Operator SOPs

## Purpose
This folder is the plain-English, non-canonical operator guide for running the Veritas OS.

Think of it as:
- responsibility guides
- simple operating checklists
- what-you-do-next notes
- human-readable explanations of the system

## Authority boundary
This folder is **not** the canonical control plane.
It must stay subordinate to:
- core doctrine files
- playbooks / protocols / standards
- workflow continuity notes
- canonical owner notes

If an SOP here conflicts with a protocol or owner note, the canonical source wins.

## What belongs here
- plain-English responsibilities
- step-by-step operator procedures
- review checklists
- handoff / escalation guidance
- "how to use the system" explanations

## What does not belong here
- machine contracts
- workflow history logs
- audits
- architecture specs
- silent authority transfers

## Current files
- `Operator Responsibilities.md`
- `Daily Summary SOP.md`

## Relationship to the procedure repository
- `06. Playbooks/Operating Procedures/` = structured operator procedure repository and classification layer
- `06. Playbooks/Operator SOPs/` = plain-English operator-facing facade

The SOP layer should stay simple.
It explains the system.
It does not redefine it.
