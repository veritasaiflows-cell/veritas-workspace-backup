Four names, one machine

GatewayLocal daemon. Owns chats and the WebSocket.
Control UIBrowser dashboard the Gateway serves.
AgentWho answers: Veritas Main plus tools.
SessionThis conversation thread.

Control UI is this kind of screen

WebChat is Control UI talking to the Gateway, usually at 127.0.0.1:18789. It is not a second product and not the model vendor.

SidebarSessions you can reopen.
ChatWhere you type and get a reply.
StatusWhat the current run is doing.

The path of one message

You type-> Gateway accepts a run-> Agent works in this session-> Reply shows in Control UI

That is the whole Day 1 loop.
