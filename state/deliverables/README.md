# Deliverables State

Machine-readable manifest state for the human deliverables shelf.

## Files

- `current-manifest.json` - current JSON manifest generated by `scripts/deliverables_publisher.py`.
- `current-manifest.sqlite` - SQLite lookup table for the same manifest.

## Boundary

This state indexes copied human deliverables. It does not replace `tmp/` proof, portfolio canon, approval records, finance SQL canon, or workflow validation artifacts.
