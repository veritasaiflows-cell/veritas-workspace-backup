# Model Portfolio

## Purpose

Define the risk envelope and alert criteria for the alerts and recommendations OS.

This is a reference framework, not a broker-connected execution system. The OS generates alerts and recommendations; it does not manage positions, sizing, or allocations.

## Risk Framework

- Planning capital base: **$10,000 flat** (reference only)
- Cash reserve target: **10% / $1,000** (context for opportunity cost)
- Investable capital: **90% / $9,000** (context, not a mandate)

## Alert Risk Tiers

Percent rules define alert context, not execution sizing. Dollar math below is for scale reference only.

- **Tier 1, high conviction:** 8% to 12% reference = **$800-$1,200** — alert triggers on band entry, thesis confirmation, or invalidation breach
- **Tier 2, moderate conviction:** 4% to 7% reference = **$400-$700** — alert triggers on band entry with secondary confirmation
- **Tier 3, speculative or asymmetric:** 1% to 3% reference = **$100-$300** — alert triggers on asymmetric risk/reward setups only

## Concentration Limits (Alert Context)

- Normal max single position: **15%** (context; alerts recommend respect)
- Stretch max: **20% to 25%** only for exceptional high-conviction alerts with explicit review
- Max single sector: **25%** (concentration risk alerting)

## Alert Design Rules

- Every alert should reference a thesis, risk envelope, catalyst path, and invalidation point
- Do not confuse conviction with concentration in alert recommendations
- Recommend rebalancing awareness, not execution
- **Alerts do not authorize trades.** All execution requires explicit human approval.

## Open Decisions

- Risk tolerance: balanced, comfortable with medium-high volatility if thesis intact
- Time horizon: multi-horizon, long-term wealth dominant
- Benchmark: broad market outperformance desirable, absolute wealth building matters
