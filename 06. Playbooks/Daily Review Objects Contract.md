# Daily Alert Review Objects Contract

## Purpose

Standardize daily market-review objects without creating a second truth layer.

Every object must contain ticker or market scope, timeframe, event time, source lineage, evidence date, freshness, confidence, thesis impact, alert state, risks, invalidation context, uncertainty, and next review action.

Use `03. Alerts and Recommendations/` as the owner layer. Generated daily objects are evidence and presentation only. They grant no action authority.
