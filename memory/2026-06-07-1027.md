**Do Not Use Spark For**

- anything that can wake main with a nuanced blocker

- exact commands
- known artifacts
- timeout set
- no external delivery
- no config/auth/runtime mutation
- no finance/canon/trade/account authority
- compact response contract
- `NO_REPLY` on clean runs
