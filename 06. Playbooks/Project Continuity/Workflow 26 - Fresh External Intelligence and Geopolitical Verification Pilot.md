# Workflow 26 - Fresh External Intelligence and Geopolitical Verification Pilot

## Objective
- Bring fresher news, macro, and geopolitical evidence into the finance OS without collapsing into rumor intake or freeform web-noise automation.
- Define how active names, macro sleeves, and geopolitical risk themes stay fresh enough to influence thesis maintenance and forward-looking direction while remaining review-first.
- Prove a bounded external-intelligence lane before any broader recurring research-monitoring expansion.

## Why this lane exists
- Randall wants fresher data from news and geopolitical events to improve decisions, thesis maintenance, and forward-looking posture.
- Workflow 21 already defines recurring source-bundle and review-window mechanics, but this workspace still needs an explicit fresh-intelligence and verification pilot focused on timely external developments.
- Fast-moving geopolitical and news events are exactly where false certainty is most dangerous, so the verification contract must be explicit before automation widens.

## Current State
- queued behind Workflow 21 as the first explicit widening step after source-bundle / review-window basics are proved
- should inherit the approved source-tier, routing, and intake-packet contracts rather than invent new trust semantics
- should feed the research department and macro / portfolio desks, not override them

## Scope
- define the approved fresh-intelligence source set for active names, macro, energy, and geopolitical sleeves
- define verification posture for unresolved or fast-moving events
- define how external developments become review packets, thesis-review candidates, or no-route verification objects
- define the pilot sleeve / theme set for recurring freshness monitoring
- prove that the lane can stay timely without becoming noisy or rumor-driven

## Out of Scope
- open-ended web trawling
- social-rumor ingestion
- autonomous thesis change
- autonomous portfolio-posture change
- autonomous publication wording changes

## Sequential phase approach

### Phase 1 - source and sleeve map
Required outputs:
- approved Tier 1 / Tier 2 source map for news and geopolitics
- blocked / rumor-heavy source classes
- pilot sleeve set (for example: energy, shipping, Fed/rates, and active catalyst names)
- unresolved-truth handling rules

### Phase 2 - manual verification-object pilot
Required outputs:
- bounded manual packet examples for fast-moving events
- at least one unresolved event that stays open honestly
- contradiction / duplicate-source examples
- operator notes on noise and miss risk

### Phase 3 - recurring review design
Required outputs:
- smallest useful recurring review cadence
- interaction with WF21 packet windows
- downgrade / stop-line rules for degraded source quality
- proof surfaces and operator action fields

### Phase 4 - usefulness verdict
Required outputs:
- keep / widen / hold decision
- named residue and next trust gap
- explicit downstream consumer map for research, macro, and portfolio desks

## Acceptance Gates
Workflow 26 should not close unless all are true:
1. approved external-intelligence source classes are explicit
2. unresolved-truth handling is explicit
3. at least one fast-moving geopolitical or news case stayed honest under verification pressure
4. the lane remained review-first and low-noise
5. downstream consumers are explicit

## Next Action
- Wait behind WF21. Once the source-bundle and packet lane is real, define the external-intelligence source map and pilot sleeve set.
