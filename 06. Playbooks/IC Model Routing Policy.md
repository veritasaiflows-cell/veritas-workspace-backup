## What Remains Here

The older Gemini and Claude notes in this playbook are historical evidence, not live routing doctrine. They can still help explain why certain provider lanes were once considered useful:

- Gemini-style lanes were treated as implementation or broad-research helpers when the CLI/runtime path was available and the contract was already clear.
- Claude-style lanes were treated as judgment/challenge helpers, with Opus reserved for unusually consequential synthesis or difficult coherence problems.
- Lower-cost or faster lanes were allowed only when the contract was narrow, the review burden was manageable, and Veritas main retained final authority.

Those principles still hold, but the canonical current matrix now lives in `veritas-model-routing-helper-lanes`.

## Current Independent-Lane Rule

Pick independent lanes by task shape, proof, and consequence:

- Use the smallest reliable model that can complete the bounded job.
- Prefer a complete deterministic/model-free command and proof contract before any model route.
- Use Codex-native Terra/low only for explicit bounded read-only work, or Terra/medium for one exact leased implementation file.
- Use a persistent Terra specialist only after a fresh strict context-transport proof passes; do not fall back silently to Main when it does not.
- Use GPT-5.6 Luna at low reasoning only for proven deterministic cron proof/digest/status `agentTurn` jobs; keep command-backed cron model-free.
- Prefer Ollama Cloud for reviewed drafts, scaffolds, formatting, long-context digestion, and challenger notes until tool-loop proof expands trust.
- Reserve GPT-5.6 Sol for main-session orchestration, high-stakes final judgment, final integration, and serious false-ready risk. Keep GPT-5.5 as primary fallback and GPT-5.4 as rollback/control.

Requested and actual backend/model/thinking must match at closeout. Compare route efficiency only across like-for-like Main-accepted jobs using uncached/gross tokens, first-pass acceptance, time, retry tax, and escaped defects. Incidents and invalid telemetry receive no success credit. Ten comparable accepted jobs is an observation gate, not automatic promotion authority.

Do not create a new routing skill for every model provider. Add provider-specific operational handling only when repeated live use proves the generic routing skill is not enough.

## Boundaries

Independent lanes are evidence producers. They do not own canonical truth, finance recommendations, queue state, workflow closeout, cron mutation, portfolio/canon mutation, customer/public output, account action, paper/live execution, or capital approval.
