# How to Read the Vault

> Archived note. This file belongs to a retired operating branch. Preserve it as historical context, not current doctrine. Current live identity and operating rules are defined by SOUL.md, IDENTITY.md, AGENTS.md, MEMORY.md, and FINANCE_SOUL.MD.

## Purpose

This document explains how Randall should navigate the workspace vault without getting lost.

## Start here

Begin with:
- `Home.md`
- `01. Dashboards/Executive Brief.md`
- `01. Dashboards/This Week.md`
- `01. Dashboards/Next Actions.md`

These files answer:
- what the overall mission is
- what is currently active
- what matters right now

The numbered top-level folders are intentional. They reflect the default review order for the vault.

## Default folder review order

1. `01. Dashboards/` - orient quickly, then decide what matters next
2. `02. Opportunities/` - review the current opportunity engine and active project
3. `03. Offers/` - review how the work turns into something sellable
4. `04. Departments/` - review domain structure and why the branch exists
5. `05. Plans/` - review execution sequence
6. `06. Training Documents/` - read deeper explanatory material when needed
7. `07. Audits/` - inspect health checks, drift findings, and cleanup history

## Then review the opportunity system

Next read:
- `02. Opportunities/Pipeline.md`
- `02. Opportunities/Scoring Rubric.md`
- the current top opportunity note

This will show:
- what opportunities exist
- how they are ranked
- what the current primary focus is
- what the next action should be

## Then review the consulting branch

Read:
- `04. Departments/Consulting/Overview.md`
- `03. Offers/Consulting Offer - Narrow Draft.md`
- `05. Plans/Consulting Launch Plan.md`

This will show:
- what the consulting direction is
- what the first offer is trying to become
- what steps remain before testing it

## Then check continuity if needed

If Randall wants the background context, read:
- `MEMORY.md`
- today's `memory/YYYY-MM-DD.md`

This explains:
- long-term truths
- what happened recently
- why certain decisions were made

## Reading order for a quick review

For a fast review in under an hour:

1. `Home.md`
2. `01. Dashboards/Executive Brief.md`
3. `01. Dashboards/This Week.md`
4. `01. Dashboards/Next Actions.md`
5. `02. Opportunities/Pipeline.md`
6. top opportunity note
7. `03. Offers/Consulting Offer - Narrow Draft.md`
8. `05. Plans/Consulting Launch Plan.md`

## Practical advice

If the vault ever starts feeling too large or too abstract, the question to ask is simple:

- what is the current primary project?
- what is the next action?
- what are we trying to monetize?

If the files do not answer those clearly, the system needs tightening.
