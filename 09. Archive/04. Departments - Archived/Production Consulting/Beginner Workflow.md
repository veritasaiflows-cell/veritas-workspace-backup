# Beginner Workflow

> Archived note. This file belongs to a retired operating branch. Preserve it as historical context, not current doctrine. Current live identity and operating rules are defined by SOUL.md, IDENTITY.md, AGENTS.md, MEMORY.md, and FINANCE_SOUL.MD.

## Goal

Create a repeatable workflow that Randall can follow without getting lost.

## Default workflow

1. Choose one idea
2. Write a hook
3. Draft a 30 to 60 second script
4. Tighten the script for spoken delivery
5. Record 2 to 5 takes
6. Pick the strongest take
7. Edit for pacing, captions, and clarity
8. Export in vertical format
9. Publish
10. Review retention and audience response
11. Improve the next video

## Operating rule

Do not try to solve every production problem at once.
Each video should improve one or two things, not ten.

## What to focus on first

1. stronger hooks
2. clearer delivery
3. cleaner cuts
4. readable captions
5. better pacing
6. more consistent posting

## What not to obsess over yet

- expensive cameras
- cinematic b-roll overload
- advanced color grading
- perfect branding systems
- overbuilt editing workflows

## Success metric for the first phase

The first win is not “viral.”
The first win is becoming capable, consistent, and visibly better over a short run of videos.
