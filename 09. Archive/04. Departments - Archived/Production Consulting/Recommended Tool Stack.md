# Recommended Tool Stack

> Archived note. This file belongs to a retired operating branch. Preserve it as historical context, not current doctrine. Current live identity and operating rules are defined by SOUL.md, IDENTITY.md, AGENTS.md, MEMORY.md, and FINANCE_SOUL.MD.

## Goal

Choose a production stack that is simple enough to start now, but good enough to produce strong short-form content.

## Recommended starting stack

### 1. Script writing and planning
- Obsidian for ideas, hooks, and script drafts
- ChatGPT / Veritas for script tightening, hook testing, and iteration

### 2. Recording
- smartphone camera first, unless a better camera is already easy to use
- external microphone if available, because bad audio kills perceived quality faster than imperfect video
- simple tripod or stable mount
- window light or a basic key light

### 3. Editing
- **CapCut** as the default recommendation for beginner-friendly short-form editing
- **DaVinci Resolve** as the next step if deeper editing power becomes necessary

## Why this stack

CapCut is the practical starting recommendation because it is fast, simple, and built around the actual needs of short-form creators.

DaVinci Resolve is more powerful, but it is also heavier and easier to overcomplicate when the real bottleneck is still scripting, delivery, and repetition.

## Tool selection rule

Do not choose tools based on what sounds most professional.
Choose tools based on whether they help you publish more high-quality reps with less friction.

## Near-term buying rule

Do not spend heavily on gear yet.
Improve skill, consistency, framing, hooks, audio, and editing judgment first.

## Current recommendation summary

If starting today:
- write in Obsidian
- record on phone
- edit in CapCut
- use simple lighting and the best microphone already available
- optimize for repetition and learning speed, not gear vanity
