**What I Found**

Web research confirms the frontier pattern for 2026-style agent systems:

- OpenAI Agents SDK: named agents, tools, MCP servers, handoffs, guardrails, structured outputs, hooks, tracing, and sandbox agents.
- LangGraph: durable execution, persistence, human-in-the-loop, long-running stateful workflows.
- AG2/AutoGen: hub-and-spoke multi-agent networks, registries, durable messaging, audit logs, governance rules.
- MCP: standardized host/client/server protocol for exposing tools and context without hardwiring every capability into one model loop.

That matches our direction. We do **not** need to abandon OpenClaw for LangGraph/AG2/CrewAI. The better move is to **borrow their architectural primitives** and make OpenClaw our self-hosted harness.

**Recommended Path**

1. **Do not expand autonomy yet.**  
   First clean the warning-grade surfaces: stale status inputs, security warnings, retrieval-quality repair, token attribution gaps, and RSI/eval maturity.

2. **Build an Agent Runtime Contract v1.**  
   Extend `agent.capabilities.json` so every persistent agent declares: role, allowed tools, denied tools, write scopes, memory scope, eval suite, max autonomy level, approval points, token budget, timeout, and closeout proof.

3. **Create a local agent message ledger before enabling config-level cross-agent messaging.**  
   Start with a SQLite/JSONL hub: `sender`, `recipient`, `task`, `artifact`, `status`, `proof`, `reviewer`, `approval_required`. Veritas remains the router. Only after that works should we consider enabling `tools.sessions.visibility=all` or `tools.agentToAgent.enabled=true`.

4. **Make evals the promotion gate.**  
   Every agent should have golden tasks. Research Scout must prove source quality. QA Red-Team must catch unsafe claims. Veritas main must integrate without hallucinating authority. No agent gets more power without passing evals.

5. **Turn key workspace scripts into a clean tool/MCP layer.**  
   Good first candidates: `workflow_router.py`, `artifact_index.py`, `finance_sql_canon_access.py`, `status_card_packet.py`, `agent_bootstrap_generator.py`, `agent_bootstrap_linter.py`, and validation routers.

6. **Sandbox later, carefully.**  
   Do not install the failed/suspicious multi-agent or context skills. If we pilot computer use, start with `open-computer-use` in a quarantined, no-credential, no-external-action test. For code sandboxing, prefer building or vetting a narrow Docker sandbox contract ourselves.

7. **Keep OpenClaw as the OS.**  
   LangGraph/AG2/CrewAI are references, not replacements. Our advantage is the local memory, finance boundaries, workflow proof, and Randall-specific operating doctrine.
