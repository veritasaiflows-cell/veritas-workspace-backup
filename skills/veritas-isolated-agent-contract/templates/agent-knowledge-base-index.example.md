# Agent Knowledge Base Index

This index is a router. It is not authority.

## Authority Sources

- `SOUL.md` governs identity, mission, and hard boundaries.
- `AGENTS.md` governs workspace operation and orchestration; its Tools section owns local runtime and tool notes.
- Skills and playbooks govern procedures.
- Generated packets provide evidence only.

## Current Sections

- `contracts/`: agent contracts, boundaries, and authority rules
- `runbooks/`: spawn, bootstrap, validation, and closeout procedures
- `self-improvement/`: summarized WF74, OTEL, validator, and owner-ticket deltas

## Rules

- Cite owner files and proof packets.
- Do not grant approval or execution authority.
- Do not duplicate secrets, raw prompts, raw tool payloads, or private/customer/account data.
- Keep generated-current context in bootstrap packets, not permanent wiki prose.
