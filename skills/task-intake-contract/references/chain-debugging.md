# Fail-Closed Chain Debugging

Read for current producer/consumer or generated-mirror failures. Missing historical lane proof follows [historical lane validation](../../veritas-workspace-audit-orchestrator/references/historical-lane-validation.md), not regeneration or canonical-path promotion. Implementation still needs the exact owner and leased scope; this branch grants no additional writes or external action.

1. **Stale versus freshly blocked input.** Inspect the artifact. A stale input has no in-chain producer regenerating it; a fresh-but-blocked input carries its own validation errors. If a consumer warns that an exact path is missing, list that parent directory for siblings before reporting that the work was never done. A timestamped dump or alternate extension next to the required name is a contract miss: the checker rejected the filename. Repair or promote the canonical path; do not describe it as a blank day. For a missing producer, wire it immediately before the consumer with minimal flags, update every exact-count/exact-order assertion, add an ordering assertion, and rerun the full chain. When the failing validator's input is regenerated by a later step of the same run, the run self-seals instead: every attempt fails before reaching regeneration, so consecutive failures all carry the same stale-input signature. Run the producer step standalone with its write flags, then rerun the full run, and add an ordering assertion covering the sequence. An empty input is not a missing input. Read the source file the producer consumed: when it legitimately contains zero items (an off-season lifecycle with no closeouts or holds, an empty window), the defect is a season-bound presence assertion in the validator, not the pipeline — make the check season-aware (pass on empty-with-indexed-source, still fail on partial drops or unindexed sources) and never fabricate rows to satisfy it. For a freshly blocked artifact, trace its validation errors one layer upstream; if that layer is outside the lease or needs external action, report the verbatim failure and stop.
2. **Healthy terminal status rejected.** If the artifact's own validation is OK, inspect its producer's accepted terminal vocabulary. Non-`ok` states can be healthy outcomes, such as sent, duplicate-quiet or weekend-quiet. Mirror that vocabulary per label in the consumer; prove every healthy state passes and a genuinely failed state still blocks. Do not rerun the producer merely to clear a classifier complaint when its content is unchanged.
3. **Producer differs between chains.** Diff the exact argv first. A missing `--validate` can create a false impression that the producer works in one chain.
4. **Generated mirrors disagree.** Use modification times to identify the stale mirror, then refresh through its owner-designated writer focused on drifted items. Preserve a legitimately flipped value as signal rather than reverting it to make parity green.

Completion: rerun the original failing gate and proportionate broader proof; classify the result as fixed, warning-grade or blocked, naming any untouched upstream scope.
