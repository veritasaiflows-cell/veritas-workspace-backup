# Workflow Executive Summaries

Purpose:
- keep one compact executive-summary folder per completed workflow
- preserve high-signal history for review, continuity, and future audits

## Folder rule
For each completed workflow, create:
- `08. Audits/Workflow Executive Summaries/Workflow <n> - <short title>/`

Minimum contents:
- `Executive Summary.md`
- optional supporting closeout artifacts or exported proof links

## Minimum executive-summary sections
- objective
- what was actually completed
- what changed in the workspace
- what remains open / named residue
- next downstream workflow or reopen trigger
- key files
- checkpoint / commit facts when relevant

## Posture
- concise, operator-readable, reality-first
- not a chain log replacement
- not a marketing recap

## Backfill rule
Going forward, every workflow close should get its folder here.
Older workflows may be backfilled later when useful, but do not pretend the archive is complete if it is not.
