# OTEL Response Contract

Use this shape for OTEL answers.

## Short Status

- Bottom line: healthy / monitor / repair / owner-gated.
- Collector: endpoint, listening state, config present.
- Fresh data: event count, metric batches, trace batches, warnings/errors, drift.
- Meaning: operational evidence only.
- Next action: one or two concrete actions.

## Recommendation Answer

- Bottom line.
- Current facts.
- Interpretation.
- P0/P1/P2 recommendations.
- Skill/workflow follow-through.
- Owner-gated items.
- Proof checked.
- Boundary held.

## Required Boundary Language

State that OTEL does not approve capital deployment, paper/live execution, account action, customer/public delivery, runtime/config mutation, external telemetry export, raw content capture, or owner approval inference.
