## Broader Reference Set

The complete tracked reference set and exact static levels live in `03. Alerts and Recommendations/Alert Bands and Invalidation Register.md`. Research admission and coverage status live in `04. Research/Coverage Universe.md`.

## Required Fields

Every current watch item must expose ticker, timeframe, thesis, evidence date, freshness, confidence, catalyst, risks, alert-band and invalidation context, and current review state.

## Boundary

Watch inclusion means “monitor evidence,” not “take action.” This file does not maintain account, capital, order, execution, or simulated-account state.
